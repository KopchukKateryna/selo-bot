# selo-bot

Тестове «Сяйво Наливайківки»: скрапер графіка ДТЕК для черги села (6.2).
GitHub Actions кожні ~10 хв бере графік і надсилає його в окремий Cloudflare Worker `selo-bot`.

Секретів немає: Worker приймає дані лише від запусків цього репозиторію (посвідчення GitHub OIDC). Адреса — будинок черги 6.2, вказаний у `.github/workflows/scrape.yml`.

Сторінка й значки — у папці `web/` (Worker бере їх звідси з кешем ~5 хв).
Копія коду Worker-а — `web/worker.js` (лише для довідки; працює код, залитий у Cloudflare).
